# Mind Mastery Lab

A self-guided learning laboratory for understanding the mind and strengthening everyday cognitive skills. Mind Mastery brings together educational explanations, interactive activities, and reflection-oriented tools to explore attention, memory, mental performance, and effective learning. It is educational rather than a diagnostic or clinical tool.

## Purpose

An interactive cognitive learning and self-development studio exploring attention, memory, thinking, mental performance, and practical evidence-informed learning strategies.

## Getting started

Open `index.html` in a modern browser, or publish the repository using GitHub Pages. The interface is intended for personal exploration and learning.

## Scope

This is an independent educational or personal-practice project. Features, accuracy, and browser support should be verified before relying on the app for consequential decisions.
